# Replication package for “Local Projections Inference with High-Dimensional Covariates without Exact Sparsity”

This package reproduces the simulation study and monetary policy empirical application in the paper.

## Components

- [`simulations/`](simulations/README.md) contains the calibrated dynamic factor model, simulation code, archived Monte Carlo output, cluster wrappers, and scripts used to reproduce the simulation figures and tables.
- [`empirics/`](empirics/README.md) contains the monetary policy application, including the empirical input file, estimation code, figures, and OGA selection diagnostics. Data provenance and the redistribution statement are provided in [`empirics/data/README.md`](empirics/data/README.md).

The two components should be run from their respective directories.

Each component contains an `install_packages.R` script with executable, version-pinned setup and check profiles. The corresponding component README gives the required R version and the exact command to use before running the analysis.

## Reproducing the paper output

### Simulation results

No external data are required. From the `simulations/` directory, run:

```bash
Rscript run_analysis.R
```

This reads the included CSV files produced by the original cluster runs and regenerates Figures 1–3, Figure S1, and Tables S3–S4. It does not rerun the individual Monte Carlo replications. Instructions for rerunning the full Monte Carlo experiment and then rebuilding these outputs are provided in the [simulation README](simulations/README.md). Tables 1, S1, and S2 are descriptive tables authored directly in the manuscript and are not generated by code.

### Empirical results

From the `empirics/` directory, run:

```bash
Rscript run_analysis.R
```

The default run re-estimates double OGA, FALP, and FAVAR and uses the included archived estimates for the computationally intensive HDLP method. Those HDLP estimates were generated by the documented CRC run and are the estimates used in Figure 4. Instructions for recomputing them with the full workflow are provided in the [empirical README](empirics/README.md).

## Data availability statement

All data required to reproduce the results are included in this replication package.

The empirical application uses the September 2021 vintage of FRED-MD, maintained by the Federal Reserve Bank of St. Louis ([FRED-MD data and historical vintages](https://www.stlouisfed.org/research/economists/mccracken/fred-databases)). The data used in the analysis were obtained from the replication package accompanying Adamek, Smeekes, and Wilms (2024), downloaded on January 18, 2026, rather than directly from the FRED-MD website. The R-format data file supplied with those replication materials and a CSV copy are included in `empirics/data/`. Variable definitions and transformations are documented in `empirics/data/README.md`.

The simulation calibration and its open-format companion files are included in `simulations/`. Their provenance, including the repository links, commit identifiers, and snapshot dates, is documented in `simulations/README.md`.

No restricted or proprietary data are required, and no external data access is needed to reproduce the reported results.

## Software and runtime

The simulations and full empirical estimation, including HDLP, were run on the CRC cluster using R 4.5.2. The default empirical replication workflow was verified separately on an Apple Silicon laptop using R 4.4.3. This workflow re-estimates double OGA, FALP, and FAVAR, uses the archived HDLP estimates from the CRC run, and regenerates Figure 4. Package versions, computing environments, installation instructions, and verification commands are documented in the corresponding component READMEs and recorded in:

```text
empirics/install_packages.R
simulations/install_packages.R
```

The installers pin the packages directly used by the replication. The complete resolved environments are recorded in the component session-information logs.

Regenerating the code-produced simulation figures and tables from the included Monte Carlo CSV files took approximately 34 seconds on an Apple silicon laptop. The default empirical workflow, which uses the included HDLP estimates, took approximately 3.2 minutes on an Apple silicon laptop.

Recomputing the full empirical results, including HDLP, took 9,844 seconds—approximately 2 hours 44 minutes—on the CRC cluster using 16 threads. Rerunning the complete Monte Carlo experiment requires substantially more computation; task-level allocations and recorded runtimes are reported in the simulation README.

All reported runtimes are approximate and depend on the processor, available memory, number of threads or concurrent tasks, software versions, and system load.
